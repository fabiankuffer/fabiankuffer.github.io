# Datenschutzerklärung

## 1. Verantwortlicher

Verantwortlich für die Verarbeitung personenbezogener
Daten im Zusammenhang mit diesem Blog ist der
Betreiber der Website.

Den vollständigen Namen, die Anschrift und die
Kontaktmöglichkeiten finden Sie in unserem
[Impressum](/impressum.html).

## 2. Allgemeine Informationen

Dieser Blog ist eine öffentlich zugängliche Website
mit Artikeln über Technik und Software.

Die Website wird mithilfe von Jekyll als statische
HTML-Website erstellt und über GitHub Pages
bereitgestellt.

Beim Besuch der Website werden personenbezogene
Daten verarbeitet, soweit dies für die technische
Bereitstellung der Website, die Sicherheit des
Hostings und die Bearbeitung von Kontaktanfragen
erforderlich ist.

Auf dieser Website werden keine eigenen
Besucherprofile erstellt und keine eigenen
Verfahren zur personalisierten Werbung oder
zum Tracking des Nutzerverhaltens eingesetzt.

## 3. Hosting und Serverprotokolle

Diese Website wird über GitHub Pages bereitgestellt,
einen Hosting-Dienst von GitHub.

GitHub stellt die technische Infrastruktur zur
Verfügung, über die die Website im Internet
abgerufen werden kann.

Weitere Informationen:

https://docs.github.com/de/pages/getting-started-with-github-pages/what-is-github-pages

### 3.2 Verarbeitete Daten

Beim Aufruf der Website werden technisch bedingt
Informationen zwischen Ihrem Endgerät und der
Hosting-Infrastruktur ausgetauscht.

Hierzu gehören insbesondere:

- IP-Adresse des anfragenden Endgeräts
- Datum und Uhrzeit des Zugriffs
- Angeforderte Internetadresse beziehungsweise Datei
- Technische Informationen zur HTTP-Anfrage
- Informationen, die Ihr Browser im Rahmen der
  Verbindung übermittelt

GitHub bestätigt ausdrücklich, dass beim Besuch
einer GitHub-Pages-Website die IP-Adresse des
Besuchers für Sicherheitszwecke protokolliert
und gespeichert wird. Dies erfolgt unabhängig
davon, ob der Besucher bei GitHub angemeldet ist.

Die genaue Zusammensetzung der von GitHub
gespeicherten Zugriffsprotokolle richtet sich
nach dessen technischer Infrastruktur.

Die Verarbeitung erfolgt, um die Website technisch

Rechtsgrundlage für die von uns veranlasste
Verarbeitung zur technischen Bereitstellung und

Buchstabe f DSGVO.

Das berechtigte Interesse besteht darin, einen
öffentlich erreichbaren, funktionsfähigen und

## 4. Cookies und lokaler Speicher

Auf dieser Website setzen wir selbst keine
Cookies zur Besucheranalyse, zur personalisierten
Werbung oder zur Erstellung von Nutzerprofilen ein.

Die von uns bereitgestellten Blogseiten verwenden
keine eigenen Funktionen, die personenbezogene
Besucherdaten im Local Storage oder Session Storage
des Browsers speichern.

Das Erscheinungsbild der Website wird anhand der
Systemeinstellungen des verwendeten Endgeräts
angepasst. Hierzu ist keine dauerhafte
Speicherung einer individuellen Einstellung
durch die Website erforderlich.

Die technische Bereitstellung erfolgt über
GitHub Pages. Soweit der Hosting-Anbieter
technisch notwendige Speicher- oder
Auslesevorgänge auf dem Endgerät durchführt,
richten sich diese nach den technischen
Anforderungen des Hosting-Dienstes.

Für technisch unbedingt erforderliche
Speicher- und Auslesevorgänge ist nach
§ 25 Abs. 2 TDDDG keine Einwilligung
erforderlich.

Soweit hierbei personenbezogene Daten
verarbeitet werden, ist die Rechtsgrundlage
für die von uns veranlasste technische
Bereitstellung der Website Art. 6 Abs. 1
Buchstabe f DSGVO.

Informationen zur Verwendung von Cookies
durch GitHub finden Sie unter:

https://docs.github.com/de/site-policy/privacy-policies/github-cookies

## 5. Schriftarten, Stylesheets und mathematische Formeln

Die für das Design dieser Website verwendeten
Stylesheets und Schriftarten werden lokal
innerhalb der Website bereitgestellt.

Dies gilt insbesondere für die zur Darstellung
mathematischer Formeln verwendeten
KaTeX-Stylesheets und KaTeX-Schriftarten.

Die mathematischen Formeln werden bereits
beim Erstellen der Website in HTML umgewandelt.

Beim Aufruf einer Seite ist deshalb keine
Verbindung zu einem externen KaTeX-Dienst
erforderlich.

Die benötigten Dateien werden über denselben
Hosting-Dienst ausgeliefert wie die übrigen
Inhalte der Website.

Dabei gelten die unter Abschnitt 3 beschriebenen
Informationen zum Hosting und zur Verarbeitung
technischer Verbindungsdaten.

## 6. Externe Inhalte und Verlinkungen

Auf dieser Website werden keine externen Videos,
Social-Media-Widgets, Werbenetzwerke oder
vergleichbaren Drittanbieterinhalte automatisch
eingebunden.

Bilder, Stylesheets, Schriftarten und andere
zur Darstellung der Blogartikel benötigte
Dateien werden über die eigene Website
bereitgestellt.

Die Website kann Links zu externen Angeboten
enthalten, beispielsweise zu GitHub, technischen
Dokumentationen oder anderen Websites.

Beim bloßen Lesen unserer Seiten wird durch
diese gewöhnlichen Links keine Verbindung
zu den verlinkten Websites hergestellt.

Wenn Sie einen solchen Link aufrufen, verlassen
Sie unsere Website und stellen eine Verbindung
zum jeweiligen externen Anbieter her.

Dabei können insbesondere Ihre IP-Adresse,
technische Verbindungsdaten und je nach
Browsereinstellung Informationen über die
zuvor besuchte Website übermittelt werden.

Für die Verarbeitung personenbezogener Daten
auf den externen Websites gelten die
Datenschutzinformationen der jeweiligen Anbieter.

## 7. RSS-/Atom-Feed

Diese Website stellt einen öffentlich abrufbaren
Atom-Feed bereit, mit dem neue Blogartikel
abonniert werden können.

Der Feed ist unter folgender Adresse erreichbar:

[Atom-Feed](/feed.xml)

Für die Bereitstellung des Feeds wird keine
Registrierung und keine Angabe personenbezogener
Kontaktdaten benötigt.

Wenn Sie den Feed über einen RSS-Reader abrufen,
wird eine Verbindung zur Hosting-Infrastruktur
unserer Website hergestellt.

Dabei werden die in Abschnitt 3 beschriebenen
technischen Verbindungsdaten verarbeitet.

Wenn Sie einen externen RSS-Reader verwenden,
kann dieser Anbieter zusätzliche personenbezogene
Daten verarbeiten. Dafür gelten dessen
Datenschutzinformationen.

Wenn Sie uns per E-Mail kontaktieren, verarbeiten
wir die von Ihnen übermittelten Informationen
zur Bearbeitung und Beantwortung Ihrer Anfrage.

Hierzu gehören insbesondere Ihre E-Mail-Adresse,
der Inhalt Ihrer Nachricht und gegebenenfalls
weitere von Ihnen freiwillig übermittelte
personenbezogene Daten.

Die Verarbeitung erfolgt auf Grundlage von
Art. 6 Abs. 1 Buchstabe f DSGVO.

Unser berechtigtes Interesse besteht darin,
eingehende Anfragen zu unserem Blog zu
bearbeiten und zu beantworten.

Sofern Ihre Anfrage auf den Abschluss oder
die Durchführung eines Vertrags gerichtet ist,
kann stattdessen Art. 6 Abs. 1 Buchstabe b
DSGVO einschlägig sein.

Empfänger der Daten sind die an der
E-Mail-Übermittlung beteiligten E-Mail-Dienstleister
und gegebenenfalls deren technische Dienstleister.

Wir speichern Ihre Nachricht, solange dies für
die Bearbeitung Ihrer Anfrage und gegebenenfalls
erforderliche Anschlusskommunikation notwendig ist.

Nach Abschluss der Bearbeitung löschen wir die
Korrespondenz, soweit keine gesetzlichen
Aufbewahrungspflichten oder sonstigen rechtlichen
Gründe einer Löschung entgegenstehen.
